# 그때 샀더라면 — 부동산 후회 계산기

서울 25개 구의 아파트 단지, 평형, 매수 연도를 고르면 그해 매매가와 현재 시세의 차액을 계산하고, 사용자의 월급을 기준으로 "그 차액을 벌려면 몇 년을 일해야 하는가"로 환산해 보여준다.

## 사용자에게 보이는 결과

- 서울 25개 구 중 하나를 고른다.
- 그 구에서 실제 거래 기록이 있는 아파트 단지명을 검색해 고른다.
- 선택한 단지에서 실제 거래된 전용면적(평형) 중 하나를 고른다.
- 선택한 단지·평형에서 실제 매수 연도만 선택지로 나타난다.
- 매수 연도를 고르면 그해 그 평형의 평균 매매가와, 같은 평형의 가장 최근 실거래가(현재 시세)를 비교해 금액 차액을 보여준다.
- 월급을 입력하면 "그 차액을 벌려면 몇 년을 일해야 하는가"를 환산한 문구가 추가로 나온다(예: "2016년에 이 집 샀으면 지금 +7억 2천, 월급 21년치").
- 월급을 입력하지 않아도 금액 차액까지는 볼 수 있다.
- 같은 평형의 최근 실거래가 자체가 없어 현재 시세를 셈할 수 없으면, 에러로 죽지 않고 "비교 불가" 상태를 보여준다.

## 승인된 범위

- 지역: 서울특별시 25개 자치구.
- 매물 유형: 아파트 매매만. 오피스텔·연립/다세대·단독/다가구·전월세는 다루지 않는다.
- 조회 기간: 실거래가 공개가 시작된 2006년 1월부터 현재까지 전체.
- 데이터 소스: 국토교통부_아파트 매매 실거래가 자료 API(`getRTMSDataSvcAptTrade`, 공공데이터포털). 요청 시 실시간으로 호출하되 서버에서 응답을 캐싱한다. API의 최신 요청·응답 명세와 유의사항은 [AGENTS.md](../../../AGENTS.md)의 "외부 API — 국토교통부 아파트 매매 실거래가 자료" 절을 따른다.

## 관찰 가능한 수용 기준

- 구를 고르면, 그 구에서 실거래 기록이 있는 단지명을 검색으로 찾아 고를 수 있다.
- 단지를 고르면, 그 단지에서 실제 거래된 전용면적 목록만 선택지로 나온다.
- 평형을 고르면, 그 단지·평형에서 실제 거래가 있었던 연도만 선택지로 나온다. 거래가 없던 해는 선택지에 나타나지 않는다.
- 연도를 고르면, 그해 그 평형의 평균 매매가와 같은 평형의 가장 최근 실거래가를 비교한 금액 차액이 나온다.
- 월급을 입력하면 금액 차액을 연 소득(월급×12)으로 나눈 "몇 년치" 문구가 함께 나온다. 차액이 음수(하락)여도 결과를 그대로 보여준다.
- 월급을 입력하지 않고 연도까지만 고르면, 환산 문구 없이 금액 차액만 나온다.
- 같은 (구, 계약년월) 조합을 다시 조회하면, 두 번째 조회부터는 서버 캐시를 사용해 외부 API를 다시 호출하지 않는다.
- 선택한 평형에 최근 실거래가 자체가 없으면 "비교 불가" 문구가 나오고 화면이 죽지 않는다.

## 확정된 제약과 근거

- **서울 25개 구 한정.** 법정동 코드 매핑과 단지명 검색 범위를 학습 프로젝트 난이도에 맞게 좁히기 위해 사용자가 확정했다.
- **읍면동 단위 선택 없음.** 국토교통부 API 자체가 법정동 코드 앞 5자리(시군구 단위)까지만 조회를 지원해 동 단위 조회가 불가능하다. 기술 제약이며 대안이 없다.
- **조회 기간은 2006년 1월부터 현재까지 전체.** "그때 샀더라면"의 스토리텔링 효과를 최대화하기 위해 사용자가 확정했다. 대신 단지 하나를 처음 조회할 때 최대 약 240회의 외부 API 호출이 발생할 수 있다.
- **서버 응답 캐싱.** 위 조회 기간 확정과 국토부 API의 일일 트래픽 제한(활용신청 계정 기준 10,000회)이 충돌해, 사용자가 캐싱으로 완화하기로 확정했다. 캐시 키는 (법정동 코드, 계약년월) 조합이며, 확정된 과거 실거래는 값이 바뀌지 않는다는 전제로 캐시를 재사용한다.
- **매수 연도 선택지는 실제 거래가 있는 연도만 제공.** 거래 없는 연도를 고른 뒤 별도 예외 처리를 하는 대신, 사용자가 선택지 자체를 실제 거래 연도로 좁히기로 확정했다.
- **같은 연도·같은 평형의 여러 거래는 평균가로 계산.** 중앙값이나 최근 1건보다 계산이 단순하다는 이유로 사용자가 확정했다.
- **현재 시세는 같은 평형의 가장 최근 실거래가 1건.** 평균이 아니라 최신 시점의 실제 거래가로 확정했다.

## 가정 (변경 가능)

- 단지명은 실거래 데이터의 원본 표기를 그대로 쓰고, 검색은 부분 문자열 일치로 처리한다. 오타·별칭을 하나로 묶는 별도 정규화는 하지 않는다.
- 전용면적은 ㎡ 원본 값과 평 환산값을 함께 보여준다.
- "몇 년치" 계산은 입력한 월급 × 12를 연 소득으로 보고 금액 차액을 나눈 값이다. 세금, 저축률, 대출 이자 등은 고려하지 않는다.

## 범위 밖

- 서울 외 지역(경기·인천·지방 등). 법정동 매핑 범위를 넘어서는 확장은 이번 범위 밖이다.
- 아파트 외 부동산 유형(오피스텔, 연립/다세대, 단독/다가구, 토지, 전월세).
- 회원가입, 로그인, 검색 기록 저장, 즐겨찾기 등 계정 기능.
- 재무·투자 상담, 취득세·양도세 등 부가 비용을 반영한 정교한 손익 계산.

## 유예된 결정

- **일일 트래픽 한도가 실제로 부족해질 때의 대응**(운영계정 전환, 조회 기간 축소 등)은 유예한다. 지금은 서버 캐싱으로 완화한다. 인터림 동작: 트래픽 초과로 국토부 API가 실패 응답을 주면, 사용자에게 "일시적으로 조회할 수 없다"는 안내만 보여주고 재시도는 하지 않는다.
- **단지명 유사 표기 통합**(오타·별칭 정규화)은 유예한다. 지금은 원본 문자열 그대로 노출하고 부분 검색만 지원하는 인터림 동작을 쓴다.

## 남은 위험

- 계약 후 1~2개월 이내 신고 건은 정정 신고로 사후 변경될 수 있어, 캐시된 "현재 시세"가 실제 최신 값과 잠시 어긋날 수 있다.
- 국토부 API 응답 지연·장애 시 조회 자체가 느려지거나 실패할 수 있다. 재시도 정책은 정하지 않았다.
- 평균가 계산은 극단치(펜트하우스 등 이례적 거래)의 영향을 받을 수 있다.
